## packages

### http

### uni-tools
* 依赖: base
* uniapp工具方法的二次封装库

### sys
* 依赖: base

* 公共接口请求库, 接口请求响应types, 消息服务


### ui
* 依赖: base
* 依赖: http
* 依赖: sys
* 依赖: uni-tools
* 依赖: api
* 公共UI组件, 业务组件, 主要为商家端、平台运营端使用
